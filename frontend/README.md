# CreatorIQ Frontend

Day 1 frontend foundation for the AI-powered creator analytics SaaS.

## Scope

- React + Vite app scaffold.
- Tailwind CSS setup.
- React Router route map.
- Axios API client and backend endpoint constants.
- Reusable dashboard and auth layout skeletons.
- Placeholder pages only; feature logic starts in later milestones.

## Commands

```bash
npm run dev
npm run build
npm run lint
```

## Environment

Copy `.env.example` to `.env` when local backend integration begins.
